# E-commerce Sales Analysis

## Project Overview
This project analyses e-commerce sales data using PostgreSQL and Power BI to identify sales trends, product category performance, regional revenue, and customer behaviour.

## Tools Used
- **PostgreSQL:** Data analysis using SQL queries
- **Power BI:** Interactive dashboard and data visualisation
- **Excel:** Dataset preparation

## Dataset
- Total records: 5,000
- Data includes order details, product categories, revenue, quantity, regions, payment methods, customer ratings, delivery days, discounts, and order dates.

## Key Analysis
- Overall sales and revenue performance
- Revenue by product category and region
- Monthly sales trends
- Customer ratings and delivery performance
- Payment method and discount analysis
- Revenue contribution by product category
- High-revenue and low-revenue segmentation

## SQL Analysis
The project includes 15 SQL queries covering aggregations, grouping, sorting, date-based analysis, and revenue segmentation.

See `ecommerce_sql_query.txt` and the SQL query screenshots in this repository.

## Power BI Dashboard
An interactive dashboard was created to explore sales performance through KPI cards, charts, and filters.
[Power BI Dashboard](powerbi_dashboard.png)

## Key Findings
- Total revenue: 5,109,775.74
- Total quantity sold: 20,224
- Average customer rating: 2.97
- Average delivery time: 6.12 days

## Project Objective
The objective of this project was to practise SQL-based data analysis and present business insights through an interactive Power BI dashboard.
